# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately by emailing
[leandrocfe@gmail.com](mailto:leandrocfe@gmail.com). Do not open a public issue.

We will acknowledge your report within 7 days and, after triage, provide an
estimated timeline for a fix and coordinated disclosure.

## Supported Versions

Security fixes are provided for the latest stable major version of
`leandrocfe/filament-apex-charts`.
